| **质感类别**                  | **词汇**               | **视觉特征与实例**                                                        |
| ------------------------- | -------------------- | ------------------------------------------------------------------ |
| **全哑光 (Ultra-Matte)**     | `Velvety`            | 天鹅绒般浓郁吸光，完全无反光。(_a velvety burgundy petal_)                        |
|                           | `Powdery / Suede`    | 干燥、柔焦的粉雾感或皮毛绒感。(_powdery lilac eyeshadow_)                         |
|                           | `Flat`               | 毫无光泽的工业漆面平光。(_a flat matte black chassis_)                         |
| **半哑半透 (Soft Sheen)**     | `Frosted`            | 磨砂打磨效果，漫反射半透光。(_frosted sea-glass green_)                          |
|                           | `Satin`              | 类似丝缎的微弱柔光，介于哑光与亮光之间。(_a satin champagne finish_)                   |
| **高反光 / 湿亮 (High Gloss)** | `Lacquered / Glazed` | 表面如封釉、大漆般坚硬平滑的高亮反光。(_lacquered piano black_)                       |
|                           | `Patent`             | 漆皮般的强反光平滑感。(_patent red stiletto heels_)                           |
|                           | `Slick / Wet-look`   | 带有潮湿浸水感的纯净高反光。(_slick, wet asphalt glistening under streetlights_) |
